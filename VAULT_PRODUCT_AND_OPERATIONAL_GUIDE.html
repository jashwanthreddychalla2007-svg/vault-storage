🛡️ VAULT — Product & Operational Manual

Enterprise Fault-Tolerant Distributed Object Storage Engine v2.0

1. Overview & Core Architecture

Vault is an enterprise-grade, fault-tolerant distributed object storage engine and live management console inspired by Ceph RADOS, MinIO, AWS S3, and Google File System (GFS).

Vault guarantees zero data loss, silent bitrot healing, and strict multi-tenant authorization over unreliable physical hardware subject to independent failure modes.

2. Key Technical Capabilities

System Component Technical Specification
Quorum & Placement CRUSH rack-aware placement ring (Rack-1, Rack-2, Rack-3); Write Quorum $W=2$, Read Quorum $R=2$, Replicas $N=3$.

4. Step-by-Step Operational & Safety Guide

Step 1: Role Authorization Testing

Use the Role Guard dropdown in the upper right. Select Platform Owner for administrative chaos access, or Viewer/Developer to test live server-side 403 Forbidden access guards.

Step 2: Safe Chaos Failure Simulation

Caution: Failure simulations temporarily degrade cluster redundancy to verify self-healing behavior.
  1. Upload a file on the STORAGE & S3 IAM tab and note its replica locations.
  2. Switch to OPERATIONS & CHAOS and click FAIL on an active node.
  3. Verify the object remains retrievable via surviving replicas.
  4. Observe the background anti-entropy scrubber auto-repair missing blocks back to 3 replicas.

Step 3: Bitrot Injection & Merkle Tree Inspection

  1. Click BITROT on a node in the Operations tab.
  2. Switch to MERKLE & INTEGRITY and click Inspect Object Merkle Graph.
  3. Review the exact byte offset and chunk index of corrupted bits identified by SHA-256 leaf comparison.
